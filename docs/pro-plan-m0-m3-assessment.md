# `pro-plan.md` 落地状态

本页按 2026-08-24 的最新审查任务书记录实现边界。状态只依据当前源码和自动化验证；路线图中的后续版本不会用空模型或占位接口标成完成。

## v0.5.3：决策正确性

| 任务 | 状态 | 当前实现 |
| --- | --- | --- |
| FF-1001 人工与加班成本 | 完成 | 正常人工、加班基础工资和加班溢价独立；两种已支持人工模式均有整数分对账和属性测试。 |
| FF-1002 容量成本单位 | 完成 | 返回单位类型、每日单位数和受影响实体；每班按技师、每单按工单计量，无定义组合在请求阶段拒绝。 |
| FF-1003 无效方案语义 | 完成 | 不可执行方案的正式 KPI、经济影响和抵消天数为 null，只保留诊断路线、指标和全部违规。 |
| FF-1004 突发风险定义 | 完成 | 分开统计事件发生、事件致损和给定事件后的致损概率；无害事件不进入新增业务损害。 |
| FF-1005 共同随机场景 | 完成 | 随机量由 seed、trial、事件类型和实体键派生；同快照与政策保存相同场景集哈希。 |
| FF-1006 A-run 重试 | 完成 | 新建、运行中复用和终态复用分别使用 201、202、200；失败或中断显式生成新 attempt，原 A 不覆盖。 |
| FF-1007 冻结 Plan 完整性 | 完成 | 新 V 保存排程与发布校验指纹；分析、报告和历史激活共用覆盖、技能、时间、旅行、锁定、返程、KPI、政策和快照检查。 |
| FF-1008 判别请求 | 完成 | COST、CAPACITY、RISK 各自只有一个 `request` 对象；并列旧字段或无关参数返回 422。 |
| FF-1009 容量 Artifact | 完成 | 容量 A 的每个选项保存规范化路线、校验报告、路线差异和输入变化，并提供列表与详情接口。 |
| FF-1010 Saga 终态 | 完成 | 锁定后上下文变化原子进入 `FAILED_CONTEXT_CHANGED`；同 key 稳定重放，新请求使用新 key。 |
